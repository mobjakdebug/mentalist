# راهنمای اتصال سرور کلودفلر (Cloudflare Worker + D1 Database) برای بازی سیاه‌بازی

این پوشه شامل کدهای سرور اختصاصی بازی **سیاه‌بازی** است که روی پلتفرم **Cloudflare Workers** و دیتابیس **Cloudflare D1 (SQL)** به صورت Real-time اجرا می‌شود.

---

## ۳ مرحله ساده برای راه‌اندازی و دیپلوی:

### مرحله ۱: نصب و لاگین در Cloudflare Wrangler
در ترمینال سیستم خود یا در سرور دستور زیر را اجرا کنید:
```bash
cd cloudflare
npx wrangler login
```

### مرحله ۲: ایجاد دیتابیس D1 و اجرای جداول (Schema)
دستور زیر یک دیتابیس ابری D1 به نام `siahbazi-db` برای شما می‌سازد:
```bash
npx wrangler d1 create siahbazi-db
```
پس از اجرا، کلودفلر یک `database_id` به شما می‌دهد (مثلا `xxxx-xxxx-xxxx`). آن را در فایل `wrangler.toml` جلوی `database_id` جایگزین کنید.

سپس جداول و سوالات پیش‌فرض روانشناسی را با دستور زیر در دیتابیس خود اجرا کنید:
```bash
npx wrangler d1 execute siahbazi-db --file=schema.sql --remote
```

### مرحله ۳: دیپلوی ورکر کلودفلر
کافیست دستور زیر را بزنید تا ورکر منتشر شود:
```bash
npx wrangler deploy
```
کلودفلر یک آدرس به شما می‌دهد، مانند:
`https://siahbazi-backend.<your-subdomain>.workers.dev`

---

## نحوه اتصال به اپلیکیشن اندروید:
۱. وارد اپلیکیشن شوید.
۲. روی آیکون چرخ‌دنده یا دکمه **«تنظیمات Cloudflare D1»** در بالای صفحه اصلی بزنید.
۳. آدرس ورکر خود را وارد کرده و دکمه **«تست و ذخیره اتصال»** را لمس کنید.
۴. وضعیت فوراً به **🟢 متصل به Cloudflare D1** تغییر می‌کند و تمامی اتاق‌ها، پیام‌های چت، پاسخ‌های مخفی و امتیازات به صورت زنده و واقعی روی دیتابیس شما ذخیره و همگام می‌شوند!
