# 🚀 راهنمای گام‌به‌گام و مصور راه‌اندازی سرور Cloudflare Worker و دیتابیس D1

این پوشه (`cloudflare/`) شامل تمامی فایل‌ها و اسکریپت‌های مورد نیاز برای میزبانی سرور و پایگاه داده بازی **سیاه‌بازی** است:

| فایل | نقش |
| :--- | :--- |
| `worker.js` | کدهای جاوااسکریپت Cloudflare Worker (نسخه امن و آماده انتشار) شامل احراز هویت توکن واقعی (Bearer Session Token)، کنترل دسترسی دقیق نقش‌ها (میزبان/ذهن‌خوان)، سیستم ضدتقلب کامل کارت‌ها، ثبت اتمیک پاسخ‌ها، سیستم عدم تکرار ۱۰۰ سوال و محاسبه امتیازات طبق GDD |
| `schema.sql` | ساختار کامل دیتابیس D1 شامل جداول (`users`, `sessions`, `rooms`, `players`, `questions`, `answers`, `messages`, `reports`)، ایندکس‌های منحصر به فرد و ۱۰۰ سوال تخصصی روانشناسی و بلوف |
| `wrangler.toml` | فایل پیکربندی ابزار Wrangler جهت بایندینگ دیتابیس `siahbazi-db` به ورکر |
| `package.json` | دستورات آماده و اسکریپت‌های اجرایی npm برای سادگی کار |

---

## ⚡ مراحل راه‌اندازی در کمتر از ۳ دقیقه:

### مرحله ۱: ورود به پوشه و لاگین
در ترمینال خود دستورات زیر را وارد کنید:
```bash
cd cloudflare
npx wrangler login
```
مرورگر باز شده و پس از تایید دسترسی به اکانت رایگان Cloudflare، پیام لاگین موفق در ترمینال نمایش داده می‌شود.

---

### مرحله ۲: ایجاد دیتابیس D1 در کلودفلر
دستور زیر را اجرا کنید:
```bash
npx wrangler d1 create siahbazi-db
```
خروجی شبیه به این دریافت خواهید کرد:
```text
✅ Successfully created DB 'siahbazi-db' in region EEUR
[[d1_databases]]
binding = "DB"
database_name = "siahbazi-db"
database_id = "xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx"
```

---

### مرحله ۳: وارد کردن `database_id` در فایل `wrangler.toml`
فایل `wrangler.toml` موجود در همین پوشه را باز کرده و `database_id` دریافتی را در خط ۹ جایگزین کنید:
```toml
[[d1_databases]]
binding = "DB"
database_name = "siahbazi-db"
database_id = "شناسه_دریافتی_شما_از_مرحله_قبل"
```

---

### مرحله ۴: اجرای ساختار جداول و سوالات روی دیتابیس ابری
دستور زیر را در ترمینال بزنید:
```bash
npx wrangler d1 execute siahbazi-db --file=schema.sql --remote
```
تمامی جداول، ایندکس‌های امنیتی و ۱۰۰ سوال تخصصی روانشناسی و بلوف به طور خودکار در دیتابیس ابری D1 ایجاد خواهند شد.

---

### مرحله ۵: انتشار (Deploy) ورکر روی کلودفلر
دستور نهایی زیر را اجرا کنید:
```bash
npx wrangler deploy
```
در خروجی ترمینال، آدرس ورکر شما به صورت زیر چاپ می‌شود:
```text
Published siahbazi-backend
  https://siahbazi-backend.<your-subdomain>.workers.dev
```

---

## 📱 نحوه اتصال به اپلیکیشن اندروید «سیاه‌بازی»
۱. اپلیکیشن را اجرا کنید.
۲. در بالای صفحه اول، روی نشانگر وضعیت D1 یا آیکون چرخ‌دنده تنظیمات ضربه بزنید.
۳. آدرس ورکر خود را در کادر وارد کنید:
   `https://siahbazi-backend.<your-subdomain>.workers.dev`
۴. دکمه **«تست اتصال و ذخیره»** را لمس کنید.
۵. نشانگر به رنگ سبز درآمده و زمان پاسخ سرور (پینگ) نمایش داده می‌شود. اکنون دیتابیس اختصاصی شما متصل است!
